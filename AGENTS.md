# KubeCurios script authoring

When asked to create or modify KubeJS scripts that use KubeCurios (items, slot
data, effects, appearances, or their recipes), read and follow
[kubecurios-scripting](.agents/skills/kubecurios-scripting/SKILL.md) before writing
the deliverable. Its five steps and their gates are mandatory, including when
the work is delegated. Do not skip user confirmation, asset intake, or the
test handoff and report. Do not launch a test client or server before the user
opts in to assisted testing.

This workflow is for authoring script projects, not for changing the mod's
Java implementation or maintaining its existing regression fixtures.
