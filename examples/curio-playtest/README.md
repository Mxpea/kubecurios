# KubeCurios 饰品试玩

这是独立的手动测试样例，不属于模组 JAR。测试服首次进服发放样品；需要补领时可运行 `/function kubecurios_demo:kit`。

| 饰品 | 操作和预期 |
| --- | --- |
| 积时戒指 | 戴在测试功能格，观察动作栏累计 tick。取下等几秒、断线重连、双戴或换同款，都不应让计时重置或重复累加。动作栏每秒刷新，接近精确切换点时也可看命中消息。 |
| 临破积时戒指 | 单独戴上耐久 `1/16` 的积时戒指，命中后应碎裂。过几秒戴回满耐久版本，累计时间应接着走。附耐久 III 的版本可用来对比损耗。 |
| 守卫戒指 | 无其他装备时生命上限 `20 → 24`，护甲 `+2`、韧性 `+1.5`，并减少普通和火焰伤害。被生物打伤后获得抗性；取下重戴不会刷新冷却。 |
| 血誓戒指 | 半血及以上按 `demo_rage` 增伤；`/scoreboard players set @s demo_rage 0` 可关闭增伤。低于半血时用 `/attribute @s minecraft:armor get` 看护甲，有无守卫套装部件分别贡献 `+8` 或 `+4`。`/tag @s add demo_exhausted` 可关闭条件护甲，`/tag @s remove demo_exhausted` 恢复。 |
| 寒霜反击戒指 | 被生物打伤时反复尝试，有概率让攻击者而非自己获得缓慢。物品提示可同时检查蓝色增伤和红色摔落易伤。 |
| 隐匿对照戒指 | 有手写说明、无自动数值提示；伤害倍率仍生效，0% 概率不会给自己发光。 |

测试服初始为创造模式。测耐久、掉血和受伤触发前，用 `/gamemode survival` 切到生存；用 `/summon minecraft:zombie ~ ~ ~3` 可以生成测试目标。测破碎时请只戴一件积时戒指；双戴时只有来源格里的那一件会扣耐久。测试环境是本机专用服，断线后可用多人游戏重新连入同一地址。

### 固定伤害对照

运行 `/function kubecurios_demo:probe_hit`，用自己作为伤害来源对临时的无护甲目标造成 8 点基础伤害，聊天栏会显示目标实际扣血及积时戒指耐久前后值。这个探针测试服务端伤害结算，不模拟客户端挥剑。

- **耐久**：切到生存，只戴一枚无附魔的积时戒指，运行一次。满耐久应显示 `16 → 15`，临破版应显示 `1 → 破碎`。
- **增伤**：只戴血誓戒指，保持半血及以上。先用 `/scoreboard players set @s demo_rage 0` 测一次，应显示 `8.00`；再把分数设为 `25` 测一次，应显示 `10.00`。

### 佩戴外观

用 `F5` 切到第三人称。戴上守卫戒指会显示金头盔，寒霜反击戒指会显示钻石胸甲，血誓戒指则会通过 Curios 渲染层显示红石挂坠。原版护甲格仍可正常使用；例如戴上真正的钻石头盔时，它会优先于守卫戒指的金头盔。卸下饰品或关闭功能格的显示可比较前后效果。两种写法见[佩戴外观 Wiki](../../docs/wiki/Wearable-Appearance.md)。
